# Nashville Housing Data Cleaning – SQL

## Project Overview

This project focuses on cleaning and standardizing the Nashville Housing dataset using SQL. The goal was to improve the quality and consistency of the data and prepare it for further analysis.

## Objectives

- Clean and standardize the housing data
- Handle missing and inconsistent values
- Identify and remove duplicate records
- Standardize data formats
- Prepare the dataset for analysis

## Tools Used

- SQL Server
- SQL

## Data Cleaning Tasks

The project includes several data cleaning operations, including:

- Standardizing date formats
- Populating missing property address information
- Splitting address fields into separate columns
- Standardizing categorical values
- Identifying and removing duplicate records
- Removing unnecessary columns

## Dataset

The project uses the Nashville Housing dataset, containing more than 56,000 housing records.
